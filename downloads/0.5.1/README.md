MORIS 0.5.1-preview · 홈과 내 기록장 분리

기존 ‘MORIS 개선판’을 지우지 말고 이 APK를 열어 업데이트하세요. 같은 패키지·서명으로 기존 기록과 가져온 AI 모델을 유지합니다.

새로운 홈:
- 식물 사진이나 기록 내용을 홈에 표시하지 않습니다.
- 모리스 로고와 인사말, 작은 새싹 그림으로 첫 화면을 구성했습니다.
- ‘대화 시작’(미저장 대화가 있으면 ‘이어서 대화’), ‘내 기록장’, ‘월간 리포트’, 오른쪽 위 ‘설정’까지 한 화면에서 누를 수 있습니다.
- 홈의 세로 스크롤을 제거했습니다. 높이가 짧거나 글자가 크면 장식을 줄여 기능 버튼 공간을 확보합니다.

내 기록장:
- 식물 사진과 이름, 식물 수정·등록/선택은 ‘내 기록장’ 안에 모았습니다.
- 미저장 대화의 이어가기·요약 확인/저장·삭제도 이곳에서 관리합니다.
- 사진과 일상 수동 기록, 저장된 날짜별 기록과 삭제도 여기에서 이용합니다.
- 설정에서 AI 모델과 목소리, 존댓말/친구 모드를 바꿀 수 있습니다.
- 수동 기록을 작성 중이면 새 대화로 덮어쓰지 않고, 기록장에서 먼저 저장하거나 정리하도록 안내합니다.

이번 업데이트는 홈과 기록 화면의 구성 변경입니다. 대화 대본과 AI 모델, 기록 DB는 바꾸지 않았습니다. 모델을 다시 다운로드할 필요가 없습니다.

검증:
- Android 전체 단위/기능/화면 테스트 52개, lint, APK 빌드 통과.
- 320x540, 412x800, 960x800, 640x320dp와 130%/150% 글자 크기에서 홈을 네이티브 렌더링하고 버튼과 텍스트의 범위·중첩·터치 크기를 검사했습니다.
- 홈에 사진·기록 원문·저장/삭제 관리 버튼이 없고, ‘내 기록장’에 사진과 미저장 관리가 나타나는 것을 시험했습니다.
- 홈 → 내 기록장 → 수동 기록 저장 → 재실행 → 기록 확인/삭제, 식물 수정, 말투 설정 재실행 회귀 테스트 통과.
- APK 패키지/버전 코드/기존 서명 및 내장 네이티브 런타임 무결성을 확인했습니다.
- 실제 갤럭시 S24 울트라에서의 화면·음성·AI 응답은 별도 확인이 필요합니다.

앱 삭제나 데이터 삭제는 기록을 지웁니다. 기존 앱을 지우지 말고 업데이트하세요. APK에는 모델 가중치·서명키·계정 비밀번호·사용자 대화나 사진을 포함하지 않습니다.
