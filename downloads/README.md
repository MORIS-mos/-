MORIS 0.4.1-preview · 반복/따라하기 응답 처리 수정판

- 기존 0.4.0-preview 검증판 위에 업데이트 설치하세요. 앱을 삭제하지 마세요.
- 모델과 로컬 기록을 유지하도록 같은 패키지·같은 서명으로 빌드합니다.
- 모리스의 앱 속 식물 동반자 역할을 더 명확히 했습니다.
- 긴 사용자 문장의 그대로 따라하기 또는 다른 질문에 동일한 직전 답을 반복하면 1회 다시 생성합니다.
- 다시 실패하면 잘못된 응답을 대화/TTS에 붙이지 않고 안내를 표시합니다. ‘답변 다시 시도’로 같은 질문을 다시 요청할 수 있습니다.
- 준비된 고정 문구로 AI 답변을 바꾸지 않습니다. 짧은 인사나 사용자가 명시적으로 요청한 따라 읽기는 제한하지 않습니다.
- 의미가 틀리거나 비슷한 말을 바꾸어 반복하는 모든 응답을 감지하는 기능은 아닙니다.
- 실제 Gemma 3 1B의 한국어 대화 품질 개선은 아직 실기기에서 검증하지 못했습니다. 단위 테스트는 실제 모델 지능을 평가하지 않습니다.
- 대화·요약 원문을 외부 AI 서버로 보내지 않습니다.

설치 후 현재 대화를 저장/종료하고 새 대화에서 확인하세요. 모델을 다시 다운로드할 필요는 없습니다.
