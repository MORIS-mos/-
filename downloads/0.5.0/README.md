MORIS 0.5.0-preview · 대화 화면과 말투 선택 개선

기존 ‘MORIS 개선판’을 지우지 말고 이 APK를 열어 업데이트해 주세요. 기존 개선판과 같은 패키지·서명이며 기록 DB와 가져온 AI 모델 파일을 유지합니다. 이전 정식 MORIS 앱과는 별도 앱입니다.

바뀐 화면과 조작:
- 홈에 식물 사진 또는 작은 새싹 그림과 대화 시작 버튼을 먼저 보여줍니다.
- 대화를 좌우 말풍선으로 구분하고, 메시지 목록만 스크롤합니다.
- 입력창과 말하기·보내기 버튼은 아래에 고정합니다. 키보드와 시스템 표시줄의 여백을 반영합니다.
- 읽기 쉬운 Noto Sans KR 보통 굵기 글꼴과 따뜻한 배경을 사용합니다.
- 답변 생성 중에는 중복 전송을 막고, 실패하거나 미완료한 답변에만 재시도를 제공합니다.
- 글을 입력하는 동안 음성 인식이 자동으로 다시 시작하지 않도록 했습니다.
- 모델 정보·진단은 ‘더 보기’ 또는 홈의 ‘음성 / AI 설정’에서 확인합니다.

말투 선택:
- 기본은 다정한 존댓말(해요체)입니다.
- 대화 상단 ‘존댓말 · 변경’ → ‘친구 모드 · 편한 반말’을 선택하면 다음 답변부터 반말로 답하도록 AI에 지시합니다.
- 같은 메뉴에서 존댓말로 돌아갈 수 있습니다. 선택은 재실행 후에도 유지됩니다.
- 사용자의 반말 입력만으로 친구 모드로 바뀌지 않습니다.
- 말투를 바꾸면 AI 세션을 새 지시로 구성하고 기존 대화 기록을 다시 전달합니다. 화면의 과거 대화는 수정하지 않습니다.
- 사용자가 준비 중인 대본/대화 예시는 아직 반영하지 않았습니다. 실제 모델이 항상 지시를 지키는지는 기기에서 추가 확인이 필요합니다.

기존 AI 모델을 다시 다운로드할 필요 없이 화면 업데이트를 사용할 수 있습니다. 기존 Gemma LiteRT 모델의 한국어 응답 품질 한계는 화면 변경과 별개로 남을 수 있습니다. 선택한 모델은 대화의 ‘더 보기 → 선택한 AI 확인’에서 확인하세요.

검증:
- Android 단위·기능·화면 테스트 48개, lint, debug APK 빌드 통과.
- Robolectric 네이티브 렌더링으로 320·412·960dp 너비의 빈 대화/대화/생성 중/재시도 상태, 130% 글자 크기와 키보드에 준하는 짧은 높이를 확인했습니다.
- 앱에서 말투를 변경한 후 재실행해 선택이 유지되는지, 말투 변경 시 AI 지시와 세션이 바뀌고 과거 기록이 보존되는지 시험했습니다.
- 기존 기록 저장·재실행·삭제 흐름도 통과했습니다.
- APK 서명과 패키지, 버전 코드, 런타임 무결성을 확인했습니다.
- 실제 갤럭시 S24 울트라의 키보드/마이크/AI 발화 품질은 아직 확인하지 못했습니다.

모델 가중치, 서명키, 비밀번호, 사용자 대화나 사진은 포함하지 않습니다. 앱 삭제나 데이터 삭제는 기록을 지우므로 하지 마세요.
