MORIS 0.4.2-preview · GGUF 한국어 모델 지원 검증판

**앱 업데이트와 새 AI 모델 선택이 모두 필요합니다.** 기존 Gemma 1B 파일을 계속 사용하면 기존 응답 품질 문제가 남을 수 있습니다.

1. 설치 APK를 열어 기존 0.4.1-preview 위에 업데이트합니다. 앱은 삭제하지 마세요.
2. 아래 새 모델 파일을 Wi-Fi에서 다운로드합니다 (약 2.5GB, 여유 공간 8GB 이상 권장).
3. 앱 홈 → 음성 / AI 설정 → 로컬 AI 모델 파일 불러오기 → 다운로드한 `.gguf` 파일을 선택합니다.
4. 준비가 끝나면 이전 대화를 저장·종료하고 새 대화로 시험합니다.

변경 사항:
- 앱 내부의 llama.cpp CPU 실행기를 추가했습니다. 대화는 앱 전용 Unix 소켓으로만 전달되며 인터넷 추론 서버로 보내지 않습니다.
- 기존 LiteRT 모델도 계속 사용할 수 있습니다. GGUF는 파일 내용으로 구분하여 새 실행기를 사용합니다.
- 기존 검증판과 같은 패키지·서명이며 로컬 기록 DB는 변경하지 않았습니다.
- 새 모델 불러오기가 실패하면 기존 모델 파일을 복원합니다. 성공하면 새로 선택한 모델로 교체합니다.
- 모델 가중치와 서명키·비밀번호·사용자 기록은 APK에 포함하지 않았습니다. 모델은 별도 다운로드입니다.

검증 범위:
- Android 빌드/lint와 단위·화면 상태 테스트 42개 통과.
- Linux의 실제 GGUF 모델 추론 10개 응답에서 그대로 따라하기/직전 답 반복은 관찰되지 않았으며, 앞서 말한 원인과 식물이 컵을 들 수 없다는 질문 등을 구분했습니다.
- 별도 Unix 소켓의 실제 추론 응답 5개도 확인했습니다. 이 결과는 테스트 더블이 아닙니다.
- 일부 답변에는 말하지 않은 사정을 덧붙이거나 부자연스러운 말투가 남았습니다. 일반적인 사실 정확성이나 자연스러운 한국어를 보장하지 않습니다.
- **갤럭시 S24 울트라에서 새 실행기의 시작·메모리·속도·발열·대화 품질은 아직 사용자 확인이 필요합니다.** Linux 측정값은 휴대폰 성능값이 아닙니다.
